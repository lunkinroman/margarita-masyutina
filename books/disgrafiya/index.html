Дисграфия

Три пособия для коррекции ошибок на письме у младших школьников: смешения букв, обозначающих звонкие и глухие согласные, трудностей обозначения мягкости согласных и смешения сходных по начертанию букв. В каждой книге представлена система занятий по выбранному направлению.

  • 5,0 1000+ оценок Выбор покупателей
  • Авторы Маргарита Масютина, Любовь Попова
  • Издательство «Феникс»

[ Книга #01 ]

Дисграфия: мягкие против твёрдых согласных

Для младших школьников, которые пропускают буквы, путают гласные, забывают про мягкий знак и недописывают слова.

[ Книга #02 ]

Дисграфия: звонкие против глухих согласных

Для младших школьников, которые путают на письме парные согласные б–⁠п, д–⁠т, в–⁠ф, г–⁠к, ж–⁠ш, з–⁠с, с трудом воспринимают информацию на слух и запоминают инструкции.

[ Книга #03 ]

Дисграфия: буквы против букв

Для учеников, которые путают на письме буквы и–⁠у, б–⁠д, т–⁠п, ш–⁠щ, пишут неаккуратно, забывают про границы слов и с трудом строят предложения.
